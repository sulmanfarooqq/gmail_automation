## Onboarding Flow

### Day 1: Connect & Configure
```
1. Sign up → Create agency account
2. Connect Gmail (OAuth)
3. Add agency info (name, services, tone)
4. Invite team members
5. Guided tour of dashboard
```

### Day 2-3: First Results
```
6. First emails classified automatically
7. First AI drafts generated
8. Approve/reject first drafts
9. Configure first workflow (lead detection)
```

### Week 1: Value Realization
```
10. Connect CRM → see leads created automatically
11. Set up follow-up sequence
12. Review analytics → see time saved
13. Add FAQs to knowledge base
```

### Month 1: Optimization
```
14. Review AI accuracy → adjust prompts
15. Fine-tune workflow conditions
16. Set up daily summary
17. Team training completed
```

## Objection Handling

| Objection | Response |
|-----------|----------|
| "AI will get it wrong" | Human approval for all sensitive replies. You control the rules. |
| "Too expensive" | Calculate hours saved × your team's hourly rate. ROI in first month. |
| "Another tool to learn" | 5-min setup. If you can use Gmail, you can use this. |
| "Security concerns" | All data encrypted. OAuth tokens server-side. SOC 2 compliant. |
| "We already use HubSpot" | We integrate WITH HubSpot. No duplicate work. |
| "Our emails are too complex" | Train the AI with your knowledge base. Custom prompts per agency. |
